# キャンパス青空ジム 🌤️

龍谷大学 深草キャンパスを想定した、学生の運動習慣づくりを応援するWebサイトです。
授業のあいだや移動のついで、休憩中のすきま時間に、お金も道具もかけずに体を動かすきっかけを提供します。

スポーツ政策学生会議（Sport Policy for Japan：SPJ）に向けたゼミ企画の試作サイトです。

## 公開URL

https://ss-prg-sy.github.io/aozora_gym/

キャンパス各所にQRコード・ポスターを設置し、スマートフォンから読み込んで利用することを想定しています。

## コンセプト

「運動したい・痩せたいけど、時間もお金もない」と感じている学生に向けて、
キャンパスそのものを"分散型ジム"として活用してもらうことを目指しています。
既存のジムや新しい施設に頼らず、すでにあるキャンパス空間（階段・廊下・教室）を運動の場に変えるのが特徴です。

## メニュー（3つ）

1. **階段でカロリー消費** … 階段を1〜5階分のぼると消費するカロリーを、身近なお菓子に換算して表示
2. **歩いてどれだけ？** … 徒歩1〜10分でどれくらい歩けて何kcal消費するかを、スライダーで確かめられる
3. **すきま運動** … 座ったまま・机でできる簡単な筋トレとストレッチを紹介

## ファイル構成

- `index.html` … トップ画面（メニュー選択）
- `stairs.html` … 階段ページ
- `walk.html` … ウォーキングページ（スライダーで数値が変わる）
- `sukima.html` … すきま運動ページ（筋トレ・ストレッチ）
- `campus.css` … 全ページ共通のデザイン（見た目）

## 使い方（自分で見る場合）

5つのファイルを同じフォルダに置き、`index.html` をブラウザで開く。

## 今後の予定・課題

- サイト内の数値（カロリー・距離・換算など）は現在は仮の概算。正確な根拠に基づく値へ差し替え予定
- 龍谷大生へのアンケートなどによる効果検証
- 他大学・自治体への横展開を見据えた政策提言としての肉付け
